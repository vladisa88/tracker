# 07: Доставка напоминаний при сбоях

**What to build:** Владелец получает актуальное напоминание после временного сбоя без накопления старых сообщений; обычные параллельные исполнители не создают дубли, а постоянная проблема с ботом видна в приложении. Дополнить работающую ежедневную подборку правилами надёжности из спецификации.

**Blocked by:** 06 — Ежедневная подборка платежей.

**Status:** ready-for-agent

**User stories:** 26, 27, 28, 29, 30, 32.

- [ ] Временные сетевые ошибки и ограничения частоты вызывают повтор с задержкой с учётом ответа Telegram. Содержимое подборки остаётся зафиксированным; срок следующей попытки сохраняется после перезапуска.
- [ ] При неопределённом результате отправка повторяется. Редкий дубль между принятием Telegram и фиксацией успеха допустим и описан; документированного ключа идемпотентности у sendMessage не предполагается.
- [ ] После простоя в пределах дня подборка доставляется не раньше 10:00 и до конца дня по Москве. После полуночи старые задания и их повторы не отправляются; новая подборка рассчитывается для новой даты после 10:00.
- [ ] После долгого простоя прогноз актуализируется общим правилом расписания, без рассылки подборок за прошедшие дни.
- [ ] Атомарный захват и уникальность бизнес-даты предотвращают обычную одновременную отправку двумя исполнителями. После аварии захват можно восстановить; восстановление не создаёт бесконечно зависшую задачу.
- [ ] Постоянный отказ, например блокировка бота, фиксируется как проблема доступности и не создаёт бесконечных частых повторов. Повторный `/start` проверяет восстановление подключения.
- [ ] Ошибка доставки отражается в состоянии подключения в API и русском интерфейсе, при этом управление подписками продолжает работать.
- [ ] Детерминированные проверки с PostgreSQL, управляемым временем и Telegram покрывают временную ошибку, ограничение частоты, таймаут с неизвестным результатом, перезапуск, восстановление захвата, двух исполнителей, 14:00, полночь и многодневный простой.
- [ ] Браузерная проверка подтверждает видимую проблему бота и восстановление состояния. Записаны результаты проверок и завершение задачи.
