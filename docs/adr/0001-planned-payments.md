# Прогноз платежей без учёта фактических списаний

Первая версия помогает заранее видеть регулярные расходы и получать напоминания. Выбрана модель плановых платежей с автоматическим переходом дат: подтверждение «Оплачено» и история фактических списаний не ведутся, чтобы не требовать ручного подтверждения каждого платежа. Наступление даты не доказывает оплату; будущий учёт фактических платежей потребует отдельной модели и не сможет восстановить достоверную историю из одного расписания.
